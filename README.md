## About the Project

JUST FLYGIN is an independently developed cryptocurrency project inspired by flying-car culture, futuristic transportation concepts, science fiction, and internet meme culture.

The project combines a flying-car-inspired identity with an ERC-20 token deployed on Ethereum Mainnet.

JUST FLYGIN is a community-oriented meme token. It does not represent equity, ownership in a company, dividends, or guaranteed financial returns.

## Tokenomics

The initial token allocation is structured as follows:

| Allocation | Percentage | Token Amount |
|---|---:|---:|
| Public Allocation | 85% | 850,000,000 JFG |
| Developer Allocation | 15% | 150,000,000 JFG |
| **Total** | **100%** | **1,000,000,000 JFG** |

### Public Allocation

850 million JFG tokens are allocated for public distribution and are held in a designated public allocation wallet.

### Developer Allocation

150 million JFG tokens are reserved for the developer allocation. These tokens are held under a smart-contract lock for 365 days and become claimable by the designated developer wallet after the lock period.

## Smart Contract Features

The deployed smart contract includes:

- Fixed maximum token supply.
- ERC-20 token functionality.
- 365-day developer allocation lock.
- Buy cooldown mechanism.
- Sell-limit rules that change over time.
- Automated Market Maker (AMM) pair registration support.

These features are implemented in the deployed smart contract. Users should review the verified contract source code before interacting with the token.
